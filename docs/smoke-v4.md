# בדיקת עשן v4 – ריצה בייצור (ישראל)

סמנו כל שורה. כשל = משימה חדשה ב-`build-plan-v4.md` לפני שממשיכים. אין לשלוח לעובדים אמיתיים: להשתמש במייל שלך.

## הכנה
- [ ] **משתמשים**: ליצור משתמש "מזכירות בדיקה" עם שם משתמש וסיסמה, בלי מייל; בהרשאות לסמן "מעקב בלבד" ולהגביל לעמותה אחת.
- [ ] **ערכה**: ב"מסלולי חתימה" → ערכה → "הגדרות התהליך": תוקף "יום 4 בחודש שאחרי" שדה התאריך; נמען סיום = המייל שלך; שלבי טיפול "עודכן בשכר"; תזכורות דולקות.
- [ ] **טופס הבקשה**: בבונה, לשדה "מרכז רווח" לסמן "שדה פנימי – לצוות בלבד".

## תרחיש
- [ ] בקשה חדשה: למלא מרכז רווח, תאריך תחילה 15 בחודש. אחרי השליחה דף הבקשה מציג תוקף = ה-4 בחודש הבא.
- [ ] מסך "עובדים": העובד מופיע פעם אחת עם הבקשה.
- [ ] קישור העובד (מהמייל או מדף הבקשה): **אין** שדה מרכז רווח, לא בטופס ולא ב"פרטים שמולאו".
- [ ] העובד ממלא וחותם → למבקש מגיע מייל "התקדמות בבקשה".
- [ ] כניסה כ"מזכירות בדיקה": נפתח מסך "מעקב חתימות" בלבד; הבקשה מופיעה עם שלב, ימים ו"ממתין ל"; אין קישור לדף הבקשה; כתובת `/admin/requests/<id>` ישירה → חוזר למעקב; הורדת PDF → 404.
- [ ] כמזכירות: "תזכורת" → "התזכורת נשלחה"; לחיצה שנייה → "כבר נשלחה תזכורת בארבע השעות האחרונות".
- [ ] המאשר (מהשדה "גורם מאשר") מקבל מייל ומאשר; חשבות מאשרת.
- [ ] לנמען הסיום מגיע מייל עם ה-PDF החתום מצורף; **אין** בו מרכז רווח.
- [ ] דף הבקשה: כרטיס "טיפול אחרי החתימה" → "סימון כבוצע" (צריך הרשאת "מסמן טיפול"); הבקשה נעלמת מסינון "ממתינות לטיפול אחרי חתימה".
- [ ] ייצוא Excel מ"נתונים וייצוא": עמודת מרכז רווח ועמודת "עודכן בשכר" קיימות.
